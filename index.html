    Détails du colis

    Options des transporteurs

    Liste des valeurs de transporteur trouvées dans la base de données. Cochez le transporteur connu auquel associer chaque valeur (utile quand l'orthographe exacte dans vos CSV ne correspond pas automatiquement à un transporteur pris en charge).

    Options des algorithmes de recherche

    Ces algorithmes transforment un numéro collé ou scanné dans le champ de recherche (ex. extraction du numéro de suivi depuis un code-barres) avant de chercher une correspondance en base.

    Configuration du scraping

    Paramètres partagés par le scraping automatique (bouton "Scrapping (Vercel)") de tous les transporteurs pris en charge (4PX, YANWEN, ...) : la fonction backend ouvre la page de suivi dans un navigateur headless, clique sur le bouton de copie des résultats et lit le résultat.

    Options d'import CSV

    Scanner un code-barres / QR code

    Pointez la caméra vers le code-barres ou le QR code du colis. La fenêtre se ferme automatiquement dès qu'une valeur est détectée.
